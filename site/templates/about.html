About & method

Launch Delay Watch is an open-source dataset and site that tracks how rocket launch NET (no-earlier-than) dates move over time.

Method

  1. Once a day a GitHub Action makes one request to the Launch Library 2 launch/upcoming endpoint (next 100 launches) and commits the result as a CSV.
  2. Each snapshot is compared with the previous day's. A launch present in both is one comparison; slip_days = new NET − old NET.
  3. A comparison counts only if both NETs are given to the hour or better. Day, month, quarter and year placeholders (for example 2026-11-30T00:00:00Z for "sometime in November") are excluded, and a switch between a placeholder and a real time is flagged as a precision change, not a slip.
  4. A slip is a move later of at least 1 hour. Smaller moves are T-0 refinements (for example a liftoff late in the launch window) and are reported separately.

Precision comes from Launch Library 2's net_precision field (recorded from 2026-11-16). Earlier snapshots use a heuristic that matched that field on all 100 upcoming launches checked on 2026-11-16: a NET at exactly 00:00:00 UTC with a zero-length window is a placeholder. Run ldw headline to reproduce every published number.

Limitations

  • One snapshot per day (taken mid-day UTC, not at a fixed minute), so moves that happen and reverse within a day are missed, and slip counts are a lower bound.
  • Only the next 100 upcoming launches are captured; launches farther out appear only once they enter that window.
  • A NET is a public target, not an official range schedule. Launch Library 2 is curated by volunteers from public sources and can lag or differ from provider announcements.
  • The record started on 2026-11-03, so the sample is still small.

Attribution

Launch records come from Launch Library 2 by The Space Devs, used under their terms of use. This project is not affiliated with The Space Devs. Please credit them when you reuse launch data. This site only reads committed CSV snapshots; it does not call the API at build time.
