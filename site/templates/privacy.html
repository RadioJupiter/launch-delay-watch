Privacy

This is a static documentation/data site hosted on GitHub Pages.

What we collect

The site itself does not run a backend or account system. No ads are currently shown, and there is no newsletter signup form. If advertising (e.g. Google AdSense) is added later, those third parties may set cookies or collect usage data under their own policies — those scripts will not run until explicitly enabled in the templates.

We use GoatCounter for privacy-friendly visitor counts. It sets no cookies and collects no personal data; it records page views, referrers, and coarse browser/screen/country info.

Visiting GitHub Pages may be logged by GitHub according to GitHub’s privacy statement.

Affiliate links

No affiliate links are currently active. If Amazon Associates (or similar) links are added later, purchases through those links may earn a commission at no extra cost to you, and an FTC disclosure will appear near those links.

Contact

Questions or privacy requests: open an issue on the GitHub repository.
